Search all of Wikipedia three ways.

Every passage of English Wikipedia, on a 2 GB node that holds none of it in memory. Each search is a cold read from object storage — semantic, keyword, or both fused into one query.

Queries are embedded on this host — no external model API, no GPU. The same search is one HTTP call: curl 'https://demo.polign.com/demo/search?q=…&mode=hybrid'
